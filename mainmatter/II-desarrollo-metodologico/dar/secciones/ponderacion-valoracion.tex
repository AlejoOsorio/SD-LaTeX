\subsection{Ponderación y valoración}\label{subsec:dar-ponderacion}

Para el análisis \ac{DAR}, se asignó a cada criterio una ponderación de acuerdo con su importancia dentro del proceso de selección. La suma de las ponderaciones establecidas fue de 52 puntos.

Las alternativas fueron valoradas en una escala de 0 a 5, de acuerdo con el nivel de cumplimiento observado para cada criterio. La puntuación ponderada se obtuvo multiplicando la valoración asignada a cada tecnología por el peso correspondiente al criterio y sumando posteriormente los resultados obtenidos.
