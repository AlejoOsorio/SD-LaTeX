En este capítulo se definen los objetivos que orientan el desarrollo del proyecto, estableciendo una relación entre el objetivo general y los objetivos específicos necesarios para su cumplimiento. Estos objetivos se centran en el análisis, selección, diseño e implementación de un servicio de directorio para el grupo de investigación \ac{GRID}, con el propósito de dar respuesta a las necesidades y oportunidades previamente identificadas.

\section{Objetivo general}\label{sec:objetivo_general}

Implementar un servicio de directorio para la infraestructura del grupo de investigación \ac{GRID} de la Universidad del Quindío

\section{Objetivos específicos}\label{sec:objetivos_especificos}
\begin{itemize}
  \item Identificar la necesidad funcional y técnica del \ac{GRID} con relación a un servicio de directorio.
  \item Caracterizar alternativas de software libres/código abierto para la implementación de un servicio de directorio en la infraestructura del grupo de investigación \ac{GRID}.
  \item Seleccionar una alternativa de software libre/código abierto para la implementación de un servicio de directorio en la infraestructura del grupo de investigación \ac{GRID}.
  \item Diseñar el servicio de directorio para el \ac{GRID} según la arquitectura de software seleccionado.
  \item Implementar prototipo funcional del servicio de directorio para el \ac{GRID}.
  \item Validar prototipo funcional del servicio de directorio implementado para el \ac{GRID}.
\end{itemize}
